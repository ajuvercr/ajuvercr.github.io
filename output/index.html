ABOUT {

// whoami

PhD researcher in Computer Science Engineering at Ghent University, building open-source developer tooling, streaming RDF pipelines, and Linked Data clients for the FOSS Semantic Web community.

My work centers on live, provenance-tracked knowledge graphs — which is what led to building RDF-Connect and the Semantic Web Language Server, tools now used by other Semantic Web developers rather than just myself.

Outside of work, I'm usually bouldering, chipping away at renovating my house, or building small tools I didn't strictly need — see Projects below.
